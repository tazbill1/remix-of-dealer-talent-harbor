# Remix of Dealer Talent Harbor

Can you build an applicant tracking system that will allow a dealer group with over 40 different dealerships to be able to post jobs, but also have one centralized location to check all those job postings? The app needs to be able to push jobs to Indeed and other top job sites. We also need the ability...

Once the applicant applies, we also need automated responses to go out, one with questionnaires based off of specific jobs. Also, the ability to upload videos that would introduce the employee to the dealership. And yeah, I want to make this super intuitive, better than anything else out there.
